# Support

Start with the [quick start](README.md#quick-start), [configuration guide](docs/configuration.md) and [troubleshooting checks](docs/operations.md#troubleshooting).

Use [GitHub Issues](https://github.com/DanielVd/icinga-mcp/issues) for project-specific questions, bugs and feature requests. Include the package version, Python version, affected MCP server and tool, and a sanitized description of what happened. If the client uses a proxy or a tool-name filter, include that detail without sharing private endpoints or credentials.

Use the [security policy](SECURITY.md) for vulnerability reports. Questions about upstream Icinga behavior are best directed to [Icinga's documentation](https://icinga.com/docs/) or its support channels.
